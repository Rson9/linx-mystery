## 如何确认事实

小矽使用有限判词回应问题：是、不是、无法确定、无关、请澄清或拒绝泄露。

- 没有写进故事的细节保持未知，不把“没有证明”当成“已经证伪”。
- 少量标准问法做完整问题的精确核对，不进行关键词子串猜测。
- 自由问法由灵矽 Agent 根据当前题目的事实和边界判断。
- 完整答案按因果规准评估，引用本次输入原文，不拿历史提示替玩家作答。

## 三级提示

提示依次帮助玩家找到观察方向、缩小范围、串起因果。

如果一个方向已经被明确肯定、引用了对应事实且问题中提到了相应主题，系统会保守地跳过重复提示。仅排除一个替代假设，不视为已经知道完整事实。

跳过层级不扣分，实际给出一条提示才扣 15 分。连续未知或不完整作答只产生搭档提醒，不会自动领取提示。

## 计分

通关分数从 100 分开始：

- 每条实际使用的提示扣 15 分。
- 前 5 个计分问题不扣分，之后每个扣 2 分。
- 第一次作答不扣分，之后每次作答扣 5 分。
- 最低为 0 分；主动揭晓不计通关分数。

“是／不是／无关”计入提问次数；未知、澄清和拒绝泄露不计。模型判断未通过结构或引用校验时，不增加提问、作答次数。

## 推理回放

回放引用实际识别或输入原文、服务端判词、提示与作答事件，展示题面的错觉及完整因果，不生成虚构的玩家思考过程。

时间线最多显示最近 12 个片段，发生截断时明确标记。没有历史计时信息的记录显示“未记录”。上一局可在当前页面查看，不会把旧回放写入新会话的游戏状态。

## 内容维护

- `src/cases.js`：经典改编与公共目录投影。
- `src/library/featured.js`：项目编写的题目、事实、规准、提示和复盘说明。
- `src/library.js`：结构检查、命令解析、标准问法与提示选择。
- `src/replay.js`：计分、事件与公开回放投影。

```bash
pnpm library:check
pnpm library:check --draft path/to/draft.json
```

JSON 草稿不会自动加入可玩题库。题目应具备可解释的因果、相互一致的事实、明确的未知边界和递进提示；结构检查之外，还应核对替代解释、否定问法和错误答案，并进行独立试玩。
