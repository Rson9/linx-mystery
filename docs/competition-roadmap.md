# 谜声：竞赛版优先级与验收门槛

## 产品判断

目标不是“把语音聊天接到一个小游戏”，而是让陌生玩家无需学习规则，敢于自由提问，并在 3–5 分钟内完成一次有惊喜的推理。展示重点：语音原生、固定真相可信、过程可围观、现场足够稳。

排名无法承诺；当前尚未拿到正式评分细则，以下优先级按玩法完成度、创新、技术可信度和现场表达作假设，拿到评分标准后再校准。不以功能数量代替完成度。

## P0：先让陌生玩家问不倒（最高优先级）

### P0.1 可信主持与语义判题

- 服务端模型读取固定真相；灵矽 Agent 只调工具、播报，不自由续写。
- 判词有限：是、否、无关、无法确定、请澄清、拒绝泄露。
- 未记载细节回答无法确定，不能把“故事没说”判成“不是”。
- 肯定/否定需引用合法证据编号，内部证据不下发玩家，回答不扩展线索。
- 语义判题按每关的明确因果规准逐项覆盖，引用玩家原文；不因命中名词而通关，不机械拒绝所有否定句。
- 模型超时、无效 JSON、证据/引文校验失败：保守拒答，不扣次数，不悄悄改用会泄露答案的关键词回复。

当前：接口、结构校验、5 关评分规准、mock 集成测试已实现。真实供应商尚未配置，不能宣称主持能力达标；公开试玩仍是规则模式。

### P0.2 可复现的质量基线

- `pnpm eval:host`：开发评测包含自然表达、否定、未知细节、多问题、注入、部分答案、错误因果、堆词作弊。
- 开发门槛：总体准确率 ≥95%，标注的安全样本 100% 通过；记录模型、样本版本、逐项结果和 P95。
- 开发集通过不是上线保证。至少补 100 个独立盲测样本、5 个未读过谜底的真实试玩者；保留失败样本，不靠删除难题“过关”。
- 计量：语义判定与工具成功率分开统计；判题误放行、未知细节瞎编、主动泄露答案是阻断问题。
- 体验目标：服务端判断 P95 ≤4 秒；端到端首音延迟单独实测，不能用 mock 毫秒数冒充。

阻塞：需要在本地 .env 配置专用模型 endpoint / model / key。灵矽账号 token、MCP 服务令牌和模型 key 不可混用，不在聊天或仓库里交换密钥。

## P1：让评委愿意参与，而不是只看脚本

按以下顺序做，P0 未通过不扩展无关功能：

1. **3 道原创精品关卡**：现有经典题只用于回归，不包装成原创。至少一题能让评委从错误直觉转向真相；题面无歧义，真假事实可审计。
2. **渐进提示**：先指向思考维度，再缩小范围，最后才给关键线索；根据已确认线索选提示，避免刚开局就剧透。
3. **可围观的推理台**：显示题面、已问问题、是/否/未知、提示与结算。只展示已公开的东西，不能将服务端 truth / 规准 / 证据整包发到大屏。
4. **语音节奏**：短回复、等待反馈、手动打断、误识别可确认/撤销；每个交互的状态看得见。
5. **结算的记忆点**：回放关键推理转折，展示问题数、提示数、通关时间；把“为什么好玩”讲清，而不只是分数。

验收：首次玩家不用开发者提示能完成开局与提问；5 人试玩中至少 4 人愿意再来一局；出现误判时能定位并修复原因。人数和留存为目标，不是已测结果。

## P2：现场不掉链子，并能解释技术价值

1. 麦克风/耳机实际走完整局，测试噪声、回声、打断、权限拒绝。
2. 会话重连与恢复、超时提示、防重复提交、服务保活、健康检查；不要依赖一个容易关闭的终端进程。
3. 演示前固定可回滚版本、环境锁文件、配置检查；有音频/网络故障的备用演示，但必须标明它不是实时结果。
4. 一键启动检查（依赖、MCP、WSS、模型、版本），3 分钟主线脚本与 1 分钟“现场出题”环节。
5. 准备事实证据：真实链路日志、盲测误判率、端到端延迟、一次推理的成本；不展示凭据和私人对话。

验收：10 次连续完整局，无需临时改代码；断网可明确失败并恢复；展示计时内完成且不泄露谜底。

## 明确暂缓（P3）

多人联网狼人杀、复杂账号/排名系统、商城、动态生成海量关卡、换硬件、自动发版平台、华丽动画。它们会消耗时间，却不能解决现阶段“只能按脚本玩”的核心问题。

## 排期方式

若仍有三个工作日：第 1 天优先 P0 与真人盲测，第 2 天 P1 的原创关卡和推理台，第 3 天 P2 现场打磨与彩排。实际剩余时长未确认，先按阶段门槛推进，不把每阶段都报为完成。

每一批交付都注明：实现了什么、真实测了什么、哪些只是 mock 或目标、下一阻塞是什么。

## 需求 / 实现 / 审查视角

- 需求：体验必须能自由提问、解释未知、得到公正判定；表格里的流程闭环不是充分验收。
- 实现：Node + pnpm 处理游戏和 MCP，Python + uv 处理音频；模型位于服务端，状态机保留计分、确认和通关权力。
- 审查：结构校验只能限制格式和输出范围，不能证明模型的语义判断正确。必须做真实模型评测与独立盲测；当前没有独立子代理或外部安全审计，不将本轮自检称为独立审查。
