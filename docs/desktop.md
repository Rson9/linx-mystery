# 原生桌宠

小矽使用透明、无边框的原生窗口。平时只显示角色，空白区域穿透鼠标；不绘制浏览器标题栏或固定网页底板。

<img src="assets/xiaoxi-actions.gif" width="192" alt="小矽动作预览">

## 操作

- **点击角色**：摸摸小矽并显示操作按钮。
- **移动鼠标到角色上**：显示操作，闲置后自动收起。
- **拖动角色**：调整位置；位置保存在本机，跨屏移动保持窗口可见。
- **右键或点省略号**：打开故事、回放、休眠、静音、置顶与退出菜单。
- **展开推理台**：在同一个窗口查看题面、文字输入和线索，不另开设备连接。
- **收回桌面**：保留本局连接和进度，恢复透明角色。

默认置顶，可在菜单关闭。题库、确认和回放会临时展开窗口，关闭后恢复；麦克风权限拒绝时自动展开文字输入。

## 动作

角色采用项目生成的透明精灵图，共 57 个有效帧、九组动作：待机、左右移动、挥手、跳跃、失败、等待、思考与检查。

| 状态 | 表现 |
| --- | --- |
| 待机、休眠 | 低频待机动作 |
| 拖动 | 左右移动动作 |
| 摸摸、招呼 | 挥手或跳跃 |
| 录音 | 期待、认真听的姿态 |
| 等待判断 | 思考动作 |
| 播报 | 检查、回应动作与文字气泡 |
| 破案 | 短暂跳跃庆祝，随后恢复待机 |
| 连接异常 | 失败、等待帮助的姿态 |

动作表达状态，不提供音素级口型同步。启用系统“减少动态效果”后冻结装饰性逐帧动作，录音与游戏功能不受影响。

## 启动与构建

```bash
pnpm install --frozen-lockfile
pnpm pet
```

原生窗口使用 Electron，不需要系统 Chrome；浏览器备用入口和自动化浏览器回归仍需要 Chrome。

```bash
pnpm desktop:build
pnpm desktop:check
```

在 macOS 上构建当前机器架构，生成：

```text
dist/谜声-darwin-<架构>/谜声.app
dist/MISHENG-<版本>-mac-<架构>.zip
```

应用包含运行时、Node/SQLite 游戏引擎、桌面桥、题库与角色素材，不包含个人配置、绑定身份或游戏记录。当前交付构建为 Apple Silicon `arm64`，系统最低 macOS 13。构建采用本地 ad-hoc 签名，未做 Apple Developer ID 公证；跨机器首次打开可能需要系统确认。

## 配置目录

源码启动直接使用项目 `.env`、`data/` 和 `.local/lingxi-device.json`。已经绑定的设备不需要重新创建。

独立应用的默认目录：

```text
~/Library/Application Support/MISHENG/
```

菜单“选择配置目录”可以指定已有项目目录。目录选择与桌宠位置保存在上述目录的 `desktop.json`，不写入应用包。

也可以首次启动时明确指定：

```bash
open -a /path/to/谜声.app --args --config-dir=/path/to/linx-mystery
```

之后直接打开应用即可沿用该目录。公开服务、MCP 和 Agent 的配置见 [部署配置](deployment.md) 与 [灵矽接入](linx-integration.md)。

## 生命周期与安全

- 应用只创建一个角色窗口；重复启动显示已有窗口。
- 启动时验证本机服务身份，再复用已在线服务，不接管它们。
- HTTP 资源和 WebSocket 握手使用绑定服务角色、端口与随机挑战的证明；不能只伪造健康标识获得原生权限。
- 本机服务密钥位于配置目录的 `.local/desktop-server.key`，权限 `0600`，不进入分发包。
- 退出停止录音、播放和当前窗口连接；只关闭本次应用自己启动的服务。
- 渲染进程开启沙箱、上下文隔离，禁用 Node 集成；原生桥不提供文件读取、命令执行或任意网络能力。
- 原生消息只接受本机主页面，子框架和其他来源不能调用。
- 媒体权限只允许可信页面的音频请求，视频和屏幕采集拒绝。
- 外部导航和任意新窗口被阻止；设备绑定入口只允许在系统浏览器打开固定的灵矽后台地址。角色回复以文本显示。

运行诊断与真实平台检查见 [维护指南](maintenance.md)。
