# 三分钟演示排练

> 排练稿包含第一题的作答方向，不能发给真人盲测参与者。当前真实语音仍存在 Agent 未执行工具的阻塞，恢复并通过验收后再进行现场语音演示；不要把预录测试、模拟 Agent 或历史录像冒充现场真人试玩。

## 开场：不是让 AI 替你想

“这是小矽，一个陪你推理的小搭档。它知道故事的真相，但不能替你说出答案。你负责提问，它负责守住事实。”

打开 `pnpm pet`，展示小窗和三个新题。选择《回不去的三句话》，点击唤醒。

必须看见推理台状态从“准备开局”变成“正在推理”。只有语音、没有服务端开局记录，不能继续假装游戏已经启动。

## 0:20–1:20：让围观者一起想

- 听题后让观众用左右手模拟一次回程。
- 问一个排除假设的问题，例如道路是否临时封闭。
- 问一次方向关系；可展示语音识别与线索记录。
- 按一次提示，说明提示不会自动使用，每条扣 15 分。
- 提交完整解释：返回时面对的方向相反，因此除了倒序，还要交换左右。

真实模型可能判断错误。以服务端结果与记录为准，不把代码文本、未执行的工具调用或口头“答对了”当作有效通关。

## 1:20–2:20：不是只有分数

打开文字推理回放：

1. 题面制造了什么错觉。
2. 观众实际问过什么、得到了什么判词。
3. 哪条提示被实际使用。
4. 最后怎样连起因果。

收尾句：“顺序倒过来了，视角也要一起倒过来。”

下载无剧透破案卡，展示可以分享的角色与成绩，但不把谜底和玩家录音带走。卡片不是签名成绩，不做竞技认证宣传。

## 2:20–3:00：解释可靠性的设计

“常见问法可以内置核对，自由问题和完整解释由 Agent 判断。服务器掌握事实边界、计分、确认和输入去重；回放引用真实记录，不是模型事后替你编一段聪明的思考。”

点击下一题，展示新题与上一局文字回放。界面会为新题建立新的语音会话。

## 不做的演示

- 不开实验语音回顾抢占三分钟的主线。
- 不现场让模型临时生成无法审校的谜底。
- 不展示管理后台 token、Cookie、设备身份或模型 key。
- 不声称完成独立盲测、全面抗注入认证、实体硬件或原生透明置顶桌宠。

## 现场失败时

先停止播报，明确说明哪一环未完成。工具发现成功不等于 Agent 真正执行工具。备用规则网页可以单独演示玩法，但必须说明它不是灵矽语音主链路，不把备用演示算作主链路通过。
