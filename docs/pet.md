# 使用指南

## 启动小矽

```bash
pnpm pet
```

小矽会以透明、无边框的角色出现在桌面角落。点击或移入角色显示操作，拖动调整位置，右键打开菜单。空白区域不挡鼠标，默认置顶。

“展开推理台”可以查看题面、线索、对话与文字输入；收回桌面不打断本局。原生窗口使用 Electron，无需专用硬件。安装和配置目录见 [原生桌宠](desktop.md)。

浏览器备用入口：`pnpm pet:web`，地址 **http://127.0.0.1:3212/**。

## 选择故事

点击“选个故事”浏览题库，选中后点击“唤醒并开始”。首次游玩推荐《回不去的三句话》。浏览题库不会放弃当前进度，中途换题需要确认。

连接灵矽后，还需要收到游戏引擎的开局确认。此时状态变为“正在推理”，说话按钮才可用。

## 用语音提问

1. 点击“点击说话”，首次使用时允许应用访问麦克风。
2. 每次只问一个问题，例如“和她面对的方向有关吗？”
3. 说完再点一次，结束录音并发送。
4. 听小矽回答，或查看推理台中的文字与线索。

录音期间会显示状态和音量，单次最长 45 秒。结束、休眠或关闭页面时停止采集，不会在后台常驻监听。建议戴耳机，减少扬声器声音进入麦克风。

正在播报时，可以等待播报结束，也可以点击方块停止，或点击说话开始新的语音输入。文字发送、提示和重听会等待当前播报结束，避免多条操作相互抢占。

## 用文字继续

展开推理台，在“问一个问题”中输入文字并发送。文字与语音使用同一局进度、提示和分数，不需要重新开局。

没有麦克风权限时，界面会展开文字模式。输入框允许先编辑下一句话，播报结束后即可发送。

## 提示与作答

- **给个提示**：领取一条递进提示，每条扣 15 分；不会自动领取。
- **重听故事**：复述当前题面，不扣分。
- **我要作答**：输入完整的原因和实现方式。
- **语音作答**：先说“我的答案是……”，再说明你的推理。
- **揭晓真相**：确认后结束当前局，不计通关分数。

只罗列几个相关词，不等于完整解释。已经解释一部分时，可以继续提问，也可以重新提交。

## 结算与回放

答对后显示分数、问题数、提示数与作答次数。推理回放按实际输入和服务端判词整理，呈现“题面的错觉 → 线索 → 因果”。回放较长时只展示最近的片段，并明确标记。

点“无剧透破案卡”下载 PNG。卡片只包含题名和结算数据，不含谜底、问题原文、录音或玩家身份。

下一题会开启新的语音会话，上一局文字回放保留在当前页面。刷新或关闭页面后，这份跨会话的回放入口不再保留。正在重玩同一题时，不展示同题旧回放。

## 结束使用

- 点“让小矽休眠”：断开当前语音会话，停止录音和播放。
- 菜单“退出小矽”：结束窗口连接，关闭由本次应用启动的服务；不接管外部运行的引擎。
- 在启动服务的终端按 `Ctrl+C`：停止本次启动的服务；单独运行的游戏引擎仍由其所属进程管理。

重新唤醒会开启新会话，不会自动接续已经断开的语音局。

## 常见操作问题

| 现象 | 处理方式 |
| --- | --- |
| 连接成功，但说话按钮显示等待开局 | 等待状态变为“正在推理”；必要时点击“开始这题” |
| 麦克风未授权 | 使用文字继续，或在系统设置中允许谜声访问麦克风；浏览器入口在站点设置中授权 |
| 提示或发送按钮暂时不可点 | 等待回答与播报结束，或点击方块显式打断 |
| 等待较久 | 可打断后重听故事，先核对推理台中的计数与进度 |
| 设备正在被其他窗口使用 | 关闭或休眠其他桌面窗口，不要同时运行终端客户端 |
| 需要绑定码 | 在现有灵矽 Agent 中添加设备，填入窗口显示的绑定码，再重新唤醒 |

部署及网络问题见 [维护指南](maintenance.md)。
