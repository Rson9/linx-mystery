# 谜声首版交付报告

## 需求分析

目标：3 天内形成可通过灵矽语音交互的完整小游戏，不依赖多人凑局，不采用跑团形式。

首版范围：单玩家/同设备围坐参与、固定关卡、提问、提示、关键概念判题、结算、下一关；网页作为可独立运行的试玩与联调界面。

验收状态：

- [x] 零密钥可启动网页规则试玩。
- [x] 5 道关卡都可完成通关。
- [x] 揭晓与未完成时换关二次确认。
- [x] 分数、提示、提问次数和刷新后进度恢复。
- [x] 两种灵矽服务端协议的本地集成测试。
- [x] 桌面与手机真实浏览器完整流程。
- [ ] 灵矽平台配置和真实设备语音全链路。
- [ ] 真实模型供应商的语义增强验证。
- [ ] 公网 HTTPS 部署、监控、数据生命周期策略。

## 代码实现

- Node.js + Express；不依赖前端打包工具。
- 原生 SQLite 持久化；同一玩家的异步请求串行处理。
- MCP 使用官方 SDK 的 Streamable HTTP transport，按实际控制台协议实现；已移除初版的旧 SSE transport。
- ASR/TTS 交由灵矽；网页 Speech API 明确标记为独立试玩功能。
- 新 AI 主持可选，提问返回有限判词和内部证据；语义判题按每关规准和玩家原文引文评估，再由状态机决定通关。输出约束不能证明语义正确，仍需真实模型评测。
- 安装及使用见 README，真机步骤见 linx-integration.md。

## 代码审查与限制

本报告包含需求、实现和审查三个视角，未使用独立子代理审计，不等同于安全认证。

已检查：

- 密钥不进入网页；无令牌时平台端点默认关闭。
- 浏览器使用不可预测的 HttpOnly / SameSite cookie。
- 处理跨站 Origin、CSP、请求体限制和基础 IP 限流。
- 平台请求认证，设备与会话分区；连接身份变化被拒绝。
- 目录不暴露谜底；未结束的状态不暴露 truth、关键词和完整事实库。
- 网页输出通过 textContent，不插入玩家提供的 HTML。
- 模型异常降级，不允许未知事实 ID 注入回复。
- npm 安装审计：0 已知漏洞（仅表示当次依赖数据库检查结果）。

已知限制：

1. 关键词判题会误拒复杂表达，也可能被关键词堆砌绕过；不是竞技产品。
2. 无模型时自然语言覆盖有限；确认一项事实可能降低谜题难度。
3. 身份头依赖可信平台及服务令牌，不防持有服务令牌者伪造设备身份。
4. 网页试玩没有正式登录，清理 cookie 后不能找回旧进度。
5. 当前部署假设单实例小流量，不具备生产级滥用防护、数据清理和横向扩容。
6. Dockerfile 已提供，但未实际构建运行。
