# 真实灵矽多轮游戏实测

## 方法

同一真实 WSS 会话，使用 macOS Tingting 合成每句话，编码为 16kHz 单声道 / 60ms Opus，经已绑定的本机虚拟设备身份发送到灵矽。接收 STT、Agent 回复和 TTS 音频，解码检查；没有直接调用游戏 HTTP API 代替语音，也没有在两轮间重置状态。

不采集麦克风、不播放扬声器，不把合成音频或身份/令牌提交仓库。此测试验证平台语音链路，不替代真实声学环境测试。

## 六轮记录

| 轮次 | 合成语音输入 | 实际回复摘要 | 结果 |
|---|---|---|---|
| 1 | 开始游戏 | 欢迎来到谜声，播报《没有响的门铃》的完整题面 | 通过 |
| 2 | 房主听力正常吗 | 可以确认：房主听不见声音 | 通过 |
| 3 | 和灯光有关吗 | 可以确认：门铃用室内闪光灯提醒房主 | 通过 |
| 4 | 给我提示 | 提示 1：门铃的提醒，不一定要靠耳朵接收 | 通过 |
| 5 | 我的答案是，房主听不见声音，门铃通过闪光灯提醒他 | 推理正确，播报固定真相，提示“下一关” | 通过 |
| 6 | 下一关 | 进入《雨天的十八楼》，播报新题面 | 通过 |

所有轮次均返回语音识别文字、完整 TTS stop 事件和可解码的 Opus 音频。ASR 中出现的标点差异没有影响本次操作。

第 5 轮完成后直接核对本地游戏服务 SQLite：

```json
{
  "status": "won",
  "questions": 2,
  "hints": 1,
  "attempts": 1,
  "score": 85
}
```

分数按引擎规则由记录计算：100 分减去 1 次提示的 15 分，提问次数未超过 5 次且首次答对，无其他扣分。

## 结论与边界

真实链路的开局、跨轮进度、事实提问、提示、判题、通关和换关已验证：合成语音 → 灵矽 ASR → Agent 工具调用 → 游戏状态机 → 灵矽 TTS → 音频解码。

仍未覆盖：真实麦克风采集、扬声器主观听感、噪声/回声、打断、断线重连、连续长时间体验、多设备并发、其他关卡的真实语音通关、揭晓和重开确认。不能将本次结果扩大为全部场景均已验收。
