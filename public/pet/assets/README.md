# 小矽角色素材

`xiaoxi.webp` 是谜声项目的角色动画，基于原有小矽形象，通过 AI 辅助生成动作并进行透明背景清理、帧提取与基线注册。

- 透明 WebP：1536 × 1872。
- 8 列 × 9 行，单元 192 × 208。
- 有效帧 57 个，剩余 15 个单元完全透明。
- 行顺序：待机、向右移动、向左移动、挥手、跳跃、失败、等待、思考、检查。
- 非跳跃动作使用统一注册缩放，跳跃保留真实离地与落地位移。

素材已通过尺寸、有效单元、透明空槽、透明像素 RGB 残留检查，并检查了动作与待机—跳跃—待机的衔接。相关检查不构成版权或独创性认证。

几何组织兼容 Codex v1；不包含 OpenAI 的内置宠物素材或官方插件源码，不需要安装 Pets 插件或登录 ChatGPT 才能播放。

角色动作预览位于仓库的 `docs/assets/xiaoxi-actions.gif`。
